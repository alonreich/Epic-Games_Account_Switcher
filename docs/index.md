# Documentation Index

Start with **`../project_structure.txt`**. It is the mandatory onboarding file for humans and AI agents: architecture, file map, rules and the change-logging workflow.

| Document | Audience | Purpose |
| :--- | :--- | :--- |
| `../project_structure.txt` | Agents / developers | Architecture, file map, non-negotiable rules, task checklist. |
| `RELEASING.md` | Maintainers | Versioning, build, signing, release and update pipeline. |

| `CHANGELOG.md` | Users | Public "What's new" history (all versions, newest first). Generated at release time. |
| `../ssl-certificate/README.md` | Maintainers | Free self-signed code-signing setup and limits. |
| `../README.md` | Users | Download, install, verify, update. |
