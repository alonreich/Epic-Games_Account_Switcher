# EPIC GAMES ACCOUNT SWITCHER: PROJECT STRUCTURE & GUIDELINES

## COMPILATION MANDATES
- THE APP MUST ALWAYS BE COMPILED AS A SINGLE-FILE INSTALLATION (.EXE).
- PRODUCING MULTIPLE FILES OR FOLDERS IN THE COMPILED DIRECTORY IS A CRITICAL FAILURE.
- TARGET ARCHITECTURE: x64 ONLY.
- DEPENDENCIES: .NET 8.0 Runtime.

## ARCHITECTURAL OVERVIEW (PURE WPF)
The application has been migrated from a Blazor/WebView2 hybrid to a **Pure WPF (Native Windows)** architecture. This was done to eliminate browser dependencies, resolve permission issues in Program Files, and improve performance.

### 1. Epic-Games_Account_Switcher-Client (WPF App)
- **MainWindow.xaml**: The native Windows UI shell. Uses a modern, high-performance card-based layout with deterministic account colors.
- **MainViewModel.cs**: Handles UI logic, data binding (MVVM), and real-time status updates via `BusyStatus`.
- **App.xaml.cs**: Handles "Smart Install", elevation, and singleton process management.
- **NO MORE WEBVIEW2**: The application is strictly native WPF. All legacy Chromium/WebView2 files have been purged.

### 2. Epic-Games_Account_Switcher-Globals (Shared Logic)
- **AccountService.cs**: The core "engine". Handles process termination, registry swapping, and safe "temporary-then-swap" file copying for account switching and capture.
- **AccountModel.cs**: Data structure for Epic Games accounts, including visual properties like `AccentColor`.
- **Globals.cs**: Shared utilities for file management, encryption, and logging.
- **Registry.cs**: Safe registry reading/writing utilities.

### 3. SingleFilePacker (.NET Utility)
- **Role**: A bootstrapper that bundles the entire `Payload` directory into a single `.zip` resource within the final EXE.
- **Function**: On launch, it extracts the payload to a temporary directory and executes the main WPF client.

### 4. Installer (C++ Bootstrapper)
- Handles runtime checks and initial setup.
- Bundled via NSIS for the final setup experience.

## DATA STORAGE GUIDELINES
- **Portable Mode**: If run from a user-owned folder, data is stored in the local directory.
- **Installed Mode**: If run from `C:\Program Files`, data is strictly stored in:
  `%LOCALAPPDATA%\Epic-Games_Account_Switcher\LoginCache\Epic_Games`
- This separation avoids Windows permission errors and ensures data persistence across updates.

## OTHER ASSETS
- **other/**: Contains web infrastructure (PHP/API) and legacy website files. These are not part of the core desktop application logic.
