# EPIC GAMES ACCOUNT SWITCHER - ARCHITECTURAL GUIDE & PROJECT STRUCTURE
# (Mandatory onboarding file for humans and AI agents. Read fully before changing anything.)

## 1) PROJECT OVERVIEW
Epic Games Account Switcher is a Windows (.NET Framework 4.8, WPF, x64) session manager for the Epic Games Launcher.
It switches accounts without login prompts by atomically swapping session tokens, web cache state and registry identifiers.
Distribution: one signed single-file installer EXE published on GitHub Releases; the app updates itself from there.

## 2) PROJECT STATUS (2026-10-16, version 3.0.0)
- Versioning: SemVer, single source of truth = Directory.Build.props (VersionPrefix). Legacy calendar versions (2026.x) compare as older.
- Release pipeline: Build.cmd (tests, signing, payload hash, SHA-256) + Release.cmd (notes promotion, annotated tag, gh release).
- Installer: two-phase (user phase not elevated / machine phase elevated from an admin-only folder), staged + atomic swap with rollback,
  downgrade guard, graceful shutdown handshake, verified safety backups, uninstall keeps accounts by default.
- Updates: in-app GitHub Releases updater (daily quiet check, Update/Later/Skip banner, SHA-256 + pinned signature verification).
- Experimental: "launcher frame" mode (opt-in) wraps the window around the Epic Games Launcher.
- Known limits: self-signed certificate does not remove SmartScreen/"Unknown publisher" for other users (see ssl-certificate\README.md).
  No delta updates (installer is ~2 MB; a verified download is reused instead of downloaded again).

## 4) CORE ARCHITECTURAL PRINCIPLES
1. **Atomicity & Rollback**: Session restoration uses `Directory.Move` on prepared temp structures. Program-file updates use staged folder + rename swap + rollback. Registry switching rolls back from snapshots.
2. **Zero-UI Mandate**: Any launcher login prompt is a logic failure. Validate tokens (JSON + binary auth) and OAuth expiry before restoring.
3. **Deterministic Lifecycle**: Epic processes are identified by install path and terminated with active polling before file I/O.
4. **Path Management**: Use consolidated properties (`LocalAppData`, `EpicSavedPath`, `Globals.InstallDirectory`). Shortcuts are created for all users by the elevated phase; old per-user shortcuts are removed in the user phase.
5. **Privilege Separation (installer)**: Elevated code runs ONLY from admin-only locations (Program Files). Never write scripts/executables to %TEMP% for elevated use. User data (backups, accounts, HKCU) is handled only in the non-elevated user phase and only after the machine phase succeeded.
6. **Never lose user data**: Never say a backup exists without `AccountService.VerifyBackupFile`. Never delete accounts without explicit user choice; uninstall keeps accounts by default.
7. **No surprise restarts**: The app never installs/restarts without explicit user confirmation. Setup asks the running app to exit gracefully (finishing any switch) before force-stopping it.
8. **Low-RAM & Safe Diagnostics**: Streaming crypto for backups; copy-on-read for locked Epic logs/INIs.

## 5) DATA MODEL
- `%LOCALAPPDATA%\EpicAccountSwitcher\EG\accounts.json` and `EG\<Id>\{Saved,EOS_Data,Roaming_Data,ProgramData_Data}`: profiles.
- `%LOCALAPPDATA%\EpicAccountSwitcher\appsettings.json`: settings (incl. AutoCheckForUpdates, SkippedUpdateVersion, ExperimentalLauncherFrame).
- `%LOCALAPPDATA%\EpicAccountSwitcher\Updates\<version>\`: verified update downloads (old ones cleaned at startup).
- `%PROGRAMDATA%\Epic-Games_Account_Switcher\Epic-Games_Account_Switcher.log`: app log.
- `%ProgramFiles%\Epic-Games_Account_Switcher\`: install folder. HKLM `...\Uninstall\Epic-Games_Account_Switcher`: Windows uninstall entry.
- `Downloads\Epic_Setup_Backup_*.egbackup` / `Epic_Uninstall_Backup_*.egbackup`: automatic verified safety backups (newest 3 kept).
- `.egbackup`: password- or CurrentUser-protected streaming-encrypted archives with HMAC-SHA256; legacy ZIPs are restore-only.
