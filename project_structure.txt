# EPIC GAMES ACCOUNT SWITCHER - ARCHITECTURAL GUIDE & PROJECT STRUCTURE

## 1) PROJECT OVERVIEW
Epic Games Account Switcher is a high-performance, atomic session manager for the Epic Games Launcher. It achieves "Zero-UI" authentication by performing surgical injections of session tokens, web cache state, and registry identifiers, bypassing all login and 2FA prompts.

## 2) PROJECT STATUS (2026-04-27)
- **Stability**: Build pipeline is 100% stabilized with intelligent pre-flight checks in `Build.cmd`.
- **Architecture**: Atomic directory swapping implemented in `AccountService.cs` to prevent session corruption.
- **Hygiene**: Dead code (including legacy CV-based AutoLogin) has been purged. Redundant path logic consolidated into class properties.
- **Verification**: Session validity (OAuth expiration) is verified before restoration to guarantee success.

## 4) CORE ARCHITECTURAL PRINCIPLES
1. **Atomicity**: Session restoration MUST use `Directory.Move` on prepared temporary structures. Never copy files into an active launcher folder one by one.
2. **Zero-UI Mandate**: Any prompt for email/password from the launcher is a logic failure. Verify tokens in `PersistentAuthStorage.json` before restoration.
3. **Deterministic Lifecycle**: Epic processes must be identified by installation path and terminated definitively before any file I/O begins.
4. **Path Management**: Always use the consolidated properties (`LocalAppData`, `EpicSavedPath`) in `AccountService.cs` to ensure path consistency.
5. **No Halt Build**: The build script is designed for automated pipelines; use `timeout /t 10` instead of `pause`.

## 5) DATA MODEL (%LOCALAPPDATA%\EpicAccountSwitcher\ & %PROGRAMDATA%\Epic-Games_Account_Switcher\)
- `EG\accounts.json`: Global account registry (%LOCALAPPDATA%).
- `EG\<Id>\` (%LOCALAPPDATA%):
  - `Saved\`: Cloned authentication and config files.
  - `EOS_Data\`: Cloned Epic Online Services local state.
  - `Roaming_Data\`: Cloned AppData/Roaming state for the launcher.
- `%PROGRAMDATA%\Epic-Games_Account_Switcher\Epic-Games_Account_Switcher.log`: Ongoing application log file.
