# EPIC GAMES ACCOUNT SWITCHER - COMPREHENSIVE PROJECT STRUCTURE (AI AGENT GUIDE)

## 1) PROJECT PURPOSE
Epic Games Account Switcher is a Windows-focused account/session switcher for Epic Games Launcher.
Core goals:
- Capture currently logged-in Epic account session into local managed storage.
- Switch between saved account sessions safely and quickly.
- Present account cards in a modern WPF UI.
- Package final distribution as a single EXE for simple delivery.


## 2) SOLUTION / TOP-LEVEL MODULES

### A) Epic-Games_Account_Switcher-Client (WPF UI)
Primary desktop application (UI + interaction orchestration).
Important files:
- App.xaml / App.xaml.cs
  - Entry point logic.
  - Install-mode enforcement, elevation flow, uninstall flow.
  - Single-instance mutex checks.
- MainWindow.xaml / MainWindow.xaml.cs
  - Main account cards screen.
  - Drag-and-drop card reordering with animated layout transitions.
  - Capture flow trigger and top-level window controls.
- MainViewModel.cs
  - Main MVVM logic, commands, async operations.
  - Account load/switch/backup/restore command handling.
- CaptureAccountWindow.xaml / .cs
  - Modal wizard to capture current account metadata and profile image.
- SkinPickerWindow.xaml / .cs
  - Skin/image picker; loads from runtime and fallback directories.
- CustomMessageBox.xaml / .cs
  - Unified custom prompt UI.


### B) Epic-Games_Account_Switcher-Globals (Shared Core Logic)
Reusable shared logic used by client and runtime operations.
Important files:
- AccountService.cs
  - Core session engine:
    - Detect current Epic account identity.
    - Capture current session files and registry state.
    - Switch to saved sessions with rollback protection.
    - Backup/restore account package.
- AccountModel.cs
  - Account entity model used in UI and persistence.
- Globals.cs
  - Common utilities: logging, file ops, process handling, shortcuts.
- Registry.cs
  - Registry read/write helpers and key path helpers.
- AppSettings.cs
  - App settings persistence for window config and behavior.
- Strings.resx / Strings.Designer.cs
  - Localized/static string resources used by app.


### C) runas (Auxiliary process)
Small helper process/project used for elevated/isolated execution scenarios.


### D) SingleFilePacker (Pack + bootstrap runtime)
Creates and uses packed payload archive for single-file distribution.
Important file:
- SingleFilePacker/Program.cs
  - --pack mode: creates Payload.zip from Payload directory.
  - Runtime mode: extracts payload to runtime location and launches main app.


### E) Installer (C++ redistributable/bootstrap installer)
C++ bootstrapper component with runtime checks and installation metadata.
Important files:
- Installer.cpp
- epic-games_account_switcher.hpp
- runtime_check.hpp
- versions.h
- Installer.vcxproj
- Installer.rc


### F) Payload (runtime publish content)
Staging folder for all files required by packaged app runtime.
Contains:
- Main app binaries
- dependencies (*.dll, runtimeconfig, deps)
- localized folders
- Skins_Icons and runas payload


### G) compiled (final delivery output)
Final expected output location for deliverable build artifact.
Required deliverable pattern:
- compiled/Epic-Games_Account_Switcher.exe


## 3) BUILD + PACKAGING PIPELINE (CURRENT EXPECTED FLOW)
1. Build solution:
   dotnet build Epic-Games_Account_Switcher.sln -c Release -p:Platform=x64
2. Publish client into Payload:
   dotnet publish Epic-Games_Account_Switcher-Client/... -o Payload
3. Publish runas into Payload/runas:
   dotnet publish runas/runas.csproj ... -o Payload/runas
4. Pack payload zip:
   dotnet run --project SingleFilePacker/SingleFilePacker.csproj -c Release -- --pack
5. Publish SingleFilePacker as final single EXE to compiled:
   dotnet publish SingleFilePacker/SingleFilePacker.csproj ... -o compiled

Result should be a single-file app in compiled folder.


## 4) RUNTIME DATA + STORAGE MODEL

### User data root
- %LOCALAPPDATA%\Epic-Games_Account_Switcher

### Important runtime files/folders
- Crash.txt (unhandled crash output)
- logs/main-log.txt (operational logging)
- LoginCache/Epic_Games/accounts.json (persisted account list)
- LoginCache/Epic_Games/<AccountId>/... (captured per-account session data)


## 5) ACCOUNT SWITCH ENGINE (HIGH LEVEL)
- Detect metadata from registry + Epic launcher files/logs.
- Capture current session (webcache/session folders + selected registry values).
- Save atomically with temp/swap patterns to reduce corruption risk.
- On switch:
  - close Epic processes,
  - save current active snapshot,
  - restore selected account snapshot,
  - apply registry identity values,
  - relaunch Epic launcher URI.
- Includes rollback/safety backup strategy if switch fails mid-operation.
