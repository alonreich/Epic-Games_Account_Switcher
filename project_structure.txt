# EPIC GAMES ACCOUNT SWITCHER - ARCHITECTURAL GUIDE & PROJECT STRUCTURE

## 1) PROJECT OVERVIEW
Epic Games Account Switcher is a high-performance, atomic session manager for the Epic Games Launcher. It achieves "Zero-UI" authentication by performing surgical injections of session tokens, web cache state, and registry identifiers, bypassing all login and 2FA prompts.

## 2) PROJECT STATUS (2026-04-27)
- **Stability**: Build pipeline is 100% stabilized with intelligent pre-flight checks in `Build.cmd`. Shell installations and uninstalls leverage multi-layered directory probing to support OneDrive Known Folder Move (KFM) and GPO folder redirections across Desktop and Start Menu paths.
- **Architecture**: Atomic directory swapping implemented in `AccountService.cs` to prevent session corruption. Backup cipher encryption and decryption utilize memory-efficient streaming (`CryptoStream`, `BoundedStream`) while maintaining full backward and forward archive compatibility.
- **Hygiene**: Dead code (including legacy CV-based AutoLogin) has been purged. Redundant path logic consolidated into class properties. All DPAPI encryption operations, registry modifications, and live Epic log extraction routines implement robust rollback, retry loops, and shadow copy-on-read fallback mechanics without silent crashes or resource handle leaks.
- **Verification**: Session validity (OAuth expiration) is verified before restoration to guarantee success. UI converters programmatically provide dark-mode avatar fallbacks for corrupted images and validate window display bounding against active monitor virtual working areas on boot.

## 4) CORE ARCHITECTURAL PRINCIPLES
1. **Atomicity & Rollback**: Session restoration MUST use `Directory.Move` on prepared temporary structures. Never copy files into an active launcher folder one by one. Shortcut generation MUST stage `.lnk` assets atomically in temporary directories before committing. Registry identity switching MUST execute complete rollback restoration from cached snapshots if any key modification fails.
2. **Zero-UI Mandate**: Any prompt for email/password from the launcher is a logic failure. Verify session tokens across both JSON and binary authentication files (`PersistentAuthStorage.json`, `PersistentAuthStorage.bin`) and validate modern binary auth blobs against OAuth expiration timestamps before restoration.
3. **Deterministic Lifecycle**: Epic processes must be identified by installation path and terminated definitively using active polling loops before any file I/O begins.
4. **Path Management & Shell Probing**: Always use the consolidated properties (`LocalAppData`, `EpicSavedPath`) in `AccountService.cs` to ensure path consistency. Installer and uninstaller shortcut deployment MUST probe all standard namespaces, Registry User Shell Folders, and OneDrive Known Folder Move (KFM) redirected desktop paths via `Globals.GetProbedDesktopDirectories()` and `Globals.GetProbedStartMenuDirectories()`.
5. **No Halt Build & Resource Cleanliness**: The build script is designed for automated pipelines; use `timeout /t 10` instead of `pause`. Single-file installer extraction and self-deletion batch scripts must enforce bounded retry limits and automatically erase incomplete staging workspaces upon failure.
6. **Low-RAM Compatibility & Safe Diagnostics**: Account profile backup encryption/decryption MUST leverage streaming cipher pipelines (`CryptoStream`/`BoundedStream`) without altering legacy archive structure or breaking backward restoration compatibility. Extraction of active Epic log files and configuration INIs MUST employ copy-on-read shadow file fallbacks to prevent silent failure during OS file lock contention.

## 5) DATA MODEL (%LOCALAPPDATA%\EpicAccountSwitcher\ & %PROGRAMDATA%\Epic-Games_Account_Switcher\)
- `EG\accounts.json`: Global account registry (%LOCALAPPDATA%).
- `EG\<Id>\` (%LOCALAPPDATA%):
  - `Saved\`: Cloned authentication and config files.
  - `EOS_Data\`: Cloned Epic Online Services local state.
  - `Roaming_Data\`: Cloned AppData/Roaming state for the launcher.
  - `ProgramData_Data\`: Cloned ProgramData launcher manifest state (%PROGRAMDATA%\Epic\EpicGamesLauncher\Data\Manifests).
- `%PROGRAMDATA%\Epic-Games_Account_Switcher\Epic-Games_Account_Switcher.log`: Ongoing application log file.
- User-created backups use password-encrypted or CurrentUser-protected `.egbackup` files processed via low-RAM streaming algorithms with verified HMAC-SHA256 headers; legacy unencrypted ZIP backups are restore-only for backward and forward compatibility.
